# US→US：英文参考稿到美规英文审核稿

本模式不做翻译式重写。先执行 SKILL.md 的共同规则，再处理以下差异。

## 正文和统计

以指定参考的英文原句、结构及共享 Web 样式为底稿。名称和规格槽位按目标替换，不因产品型号改变而摘要化整章。补充参考只在操作者指定或明确需要补齐的范围使用，并记下其型号、地区、语言、版本及单元。

记录新增／实质改写英文的单元数、原句、改后文字和依据。纯名称、参数、格式统一及恢复原文不计入。不要运行 JP 的 `count_translation.py` 把英文改动伪报成日文翻译量；使用当前英文稿的单元登记与差异表，并核对正文、图示标签、审核层和工作簿的一致性。

产品名称按[内容规则 R6](../../../../code-as-doc/content_quality_rules.md)：首句写一次全名，不加「(hereinafter referred to as "the product")」，正文用 the product；规格表、同梱品、保修句以及同时出现两个产品的句子保留全名。

新稿的内部 TBC、Q 编号、适用性解释和候选替代文案放审核区，默认隐藏；已确认参数完整保留在正文；目标缺数据的槽位按 SKILL.md 写一代值并标绿色（`title="一代数据"`），不留“—”。原句不表示目标已获批准，审核问题也不意味着允许任意弱化原文。

## 从 JHP-3000X 案例保留的检查项

这些例子说明复用方法，不能把本型号的配置或操作者决定推广成所有型号的默认值。

| 内容 | 应保留的结构或原句 | 仅在有依据时变更 |
| --- | --- | --- |
| DC/USB | PS3 警示、原首句加粗、原线缆句式、汽车电池说明及两组 CAUTION | 目标功率、输出档位与线缆要求分别核对；不把警示替换成功率介绍，不自行增加“If supported” |
| 输出恢复 | Auto Resume Conditions / Not Auto Resume Conditions 两列、合并行及全部条件 | 引导语采用本轮操作者明确提供的原文 |
| Energy Saving / LCD | 原说明段落、插图、NOTE，以及表后 App 显示设置短句 | 目标阈值、时间和确有差异的功能片段；状态词加粗并分行 |
| UPS | 原段落、接线图和警示框 | 切换时间、旁路电流、时限按目标规格；未明确的时限后行为留审核意见 |
| Charging | 简介、图、连接说明和警示的原有顺序 | 电压、电流、温度等目标参数；不按总瓦数推断太阳能板数量 |
| Troubleshooting | Error Code / Corrective Measures、合并代码行和处理步骤 | 有依据的目标差异；内部故障含义放审核区 |
| Specifications | 原分组、列宽、合并行、脚注、完整额定信息 | 目标参数和必要新增行；电气参数与温度／时限条件合理分行 |
| 质保与联系信息 | 原条款和组件 | 质保期默认 3+2 年（36 个月）并写入正文，参考非 3+2 时标紫色；操作者可逐稿改写；封底公司名、地址、邮箱、网址、电话块一律不带，质保条款内的联系方式保留 |

JHP-3000X 的 SolarSaga 200 ×4、单口两块曾由操作者明确指定；不要将这些决定当成其他目标的规格。3+2 年质保和删除封底联系信息块自 2026-10-27 起为默认值。该案例在 v0.21 统一了 `max.`，保留 `Rated`、`Surge peak` 等含义及条件。

参考图临时复用与目标硬件已验证分别登记；有目标图时优先选已登记资产，不凭外观相似替换。
