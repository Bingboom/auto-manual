# JS-100F EU English Web source

The PDF-compatible Illustrator master supplied from DingTalk is the content
authority for this Git-only target. The source file itself is intentionally not
committed; its SHA-256, oversized-artboard dimensions, English panel bounds,
deterministic extraction recipe and every Web export hash are locked by the
source and illustration manifests.

The normal build reads `phase2/` and the target-resolved page manifest through
the shared `configs/config.solar-eu-en.yaml` family config. No live table read,
write or publication action is required.
