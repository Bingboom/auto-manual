# JBP-3600A 美版英文 Git-only 转换

原稿：操作员提供的飞书 wiki 文件「Jackery Battery Pack 3600 User Manual.pdf」，7,257,682 字节，SHA-256 16ae12b0…a91c，只读下载一次后核对哈希。28 页，369×525 pt。封面型号 JBP-3600A，美国联系电话 1-888-502-2236；全书（含封底）没有印刷版本号。

页面划分：
- PDF 1 封面、2 三语前言（US/FR/ES）、3 总目录：不进网页；
- PDF 4–11 = 英文印刷页 01–08：本次转换；
- PDF 12–19 法语、20–27 西语、28 封底：不进英文网页。

发现：
- 文本层缺行。48 行可见文字是矢量轮廓，没有文本层：安全须知列表、FCC 四条措施、p6 NOTE、p7 CAUTION、p8 NOTES、STORAGE 整框、保修 Exclusions。按 4.5 倍源像素逐行转写，行框取字形路径的外接框，记在 source/text-recovery.json。这些行缩进相同，几何无法证明分句，所以每行是否开始新句按像素人工审定并记录。
- 选材顺序。先查共用库存和已发布的 JBP-3600A EU 英文网页素材。
  - 与本印刷逐像素一致的 3 张（LCD 显示、开关机、LCD 开关）原样复用。
  - 其余插图里的主机是美版 HomePower 3600 Plus（美标插座），EU 图是 Explorer 3600 Plus，或标注几何不同，所以从本 PDF 提取完整面板。
  - 11 个符号和 FCC 标志全部复用共用 native-v1 变体，逐个通过固定字形比对门槛。
- 共用组件。符号信号词表、符号图标表、FCC、包装清单、故障码表、规格表、保修引言/年限/条款、提示框，全部用共用组件；包内样式只放本源几何。

阶段：身份与选材记录 → 原生段落／表格与完整插图 → 冻结输入哈希与冷重放 → 严格 Sphinx → 320–1920 宽度浏览器检查 → Git 源码候选草稿 PR → 版面审核页。

## 操作员决定：章节顺序与法文、西文（2026-10-14）

- 章节顺序「按印刷顺序」：TROUBLESHOOTING 在 CONNECTIONS 之前，测试固定这一顺序。
- 「加法语和西语」：同一本手册的法文（PDF 12–19）和西文（PDF 20–27）正文做成两个网页版本，与英文同包。
- 三种语言版式相同、位置随译文长度平移，所以 intake 用按语言的区域表（GEOMETRY）。
- 法文、西文同样有矢量轮廓文字（FR 59、ES 61 行），按像素转写；法文撇号按印刷保留直引号或弯引号。
- 插图：译文标注在图内的面板逐语言裁切；与英文面板逐像素一致的三张（FR LCD 开关、ES 堆叠、ES 太阳能充电）直接共用英文文件。符号与 FCC 标志三种语言共用 native-v1 变体，逐语言通过字形比对。
