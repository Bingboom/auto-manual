<div class="ht-prose"><h2 id="native-p22-b4-l0-0">4. 其他说明</h2><p><span class="ht-print-medium">4.1 打开Wi-Fi&amp;蓝牙：</span></p><p>开机后自动打开Wi-Fi&amp;蓝牙，屏幕上的Wi-Fi&amp;蓝牙图标点亮表示Wi-Fi&amp;蓝牙已被打开。<br/>同时长按“AC输出按键”和“USB输出按键”1秒手动打开Wi-Fi和蓝牙。</p><p><span class="ht-print-medium">4.2 关闭Wi-Fi&amp;蓝牙：</span></p><p>两小时内未连接WiFi或蓝牙，设备上的Wi-Fi&amp;蓝牙会自动关闭。<br/>同时长按“ AC输出按键”和“USB输出按键”1秒手动关闭Wi-Fi和蓝牙。</p><p><span class="ht-print-medium">4.3 重置Wi-Fi&amp;蓝牙：</span></p><p>同时长按“总电源开关按键”和“USB输出按键”将重置 Wi-Fi和蓝牙，同时清除App中的自定义设置。</p></div>
