インレットボックスの取り付け
==============================

.. raw:: html

   <div class="hb-text-panel">
   <p><strong>設置場所の選択</strong></p>
   <p>* インレットボックスは、建物内の便利な場所に設置してください。</p>
   <p>* 製品は、乾燥した換気の良い場所に設置してください。</p>
   </div>

1.インレットボックスの前面カバーをねじって取り外します。

.. image:: ../../assets/step1-cover.png
   :alt: 手順1の図

2.インレットボックスを所定の位置に保持し、鉛筆を使用して壁に穴の位置をマークします。

.. image:: ../../assets/step2-mark.png
   :alt: 手順2の図

3\. マークした位置にドリルで穴を開け、壁アンカーを挿入します。

.. image:: ../../assets/step3-drill.png
   :alt: 手順3の図

.. raw:: html

   <div class="hb-text-panel">
   <p>* プラスチック製の壁アンカーのサイズに基づいて、適切なドリルビットを選択してください。</p>
   <p>* 穴の深さが壁アンカーの長さに一致していることを確認してください。</p>
   <p>* 壁アンカーの損傷を防ぐため、過度の力を加えないでください。</p>
   <p>* 穴あけ後、穴から破片を取り除きます。</p>
   </div>

4\. インレットボックスの背面にある取り付け穴にセルフタッピングネジを挿入し、壁アンカーにねじ込んでインレットボックスを固定します。

.. image:: ../../assets/step4-fix.png
   :alt: 手順4の図

| 5\. インレットボックスの配線用穴の1つから、自動切換スイッチまで配線を通します。
| 次のようにインレットボックス内のワイヤを接続します。

.. raw:: html

   <div class="hb-text-panel">
   <p>* 銅線のみを使用し、許可された配線方法に従ってください。</p>
   <p>* 電線管を使用する場合は、少なくとも4色の異なる色のワイヤーを通してください。</p>
   <p>* 電線ゲージ：8 AWG～10 AWG。</p>
   </div>

.. raw:: html

   <div class="hb-text-panel">
   <p>* 導体にすずメッキをしないでください。</p>
   <p>* 端子内にワイヤー絶縁体がないことを確認してください。</p>
   <p>* 電動マイナスドライバーを使用して、ネジを4.0 Nmで締めます。</p>
   </div>
