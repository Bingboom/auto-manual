安全上のご注意
==============================

.. list-table::
   :header-rows: 0
   :widths: 22 78

   * - **警告**
     - 1. インレットボックスは、設置前に電源に接続しないでください。この指示に従わない場合、電気的故障、火災、感電の原因となる可能性があります。
       2. このインレットボックスおよび関連配線の設置は、適用されるすべての電気工事規定に従い、資格のある電気技師が行う必要があります。
       3. 建造物への電力供給のために使用する場合、このインレットボックスは自動切換スイッチと組み合わせて使用する必要があります。
