<p>출력을 끄는 것을 잊어 발생하는 불필요한 배터리 소모를 방지하기 위해 본 제품은 기본적으로 에너지 절약 모드가 활성화되어 있습니다.AC 출력 또는 DC/USB 출력이 켜지면 LCD 화면에 에너지 절약 모드 아이콘이 표시됩니다.이 모드에서는 연결된 기기가 없거나 연결된 기기의 소비 전력이 특정 임계값(AC 출력 25W 또는 DC/USB 출력 2W) 미만인 경우 설정된 시간이 지나면 해당 출력이 자동으로 꺼집니다.기본 설정은 12시간입니다.에너지 절약 모드 지속 시간은 Jackery App에서 1시간, 2시간, 8시간, 12시간 또는 24시간으로 설정할 수 있습니다.Never Off로 설정하면 에너지 절약 모드는 비활성화됩니다.</p>

<p>에너지 절약 모드를 비활성화하려면 AC 전원 버튼과 메인 전원 버튼을 동시에 3초 이상 길게 누르십시오.에너지 절약 모드가 비활성화되면 LCD 화면에 아이콘이 더 이상 표시되지 않으며, 제품은 AC 또는 USB 출력을 자동으로 끄지 않습니다.</p>

<p>저전력 기기(AC &lt;= 25 W 또는 DC/USB &lt;= 2 W)에 전원을 공급할 때는 출력이 자동으로 꺼지는 것을 방지하려면 에너지 절약 모드를 비활성화하십시오.</p>

# 무정전 전원 공급 장치 (UPS)

<p>AC 충전 케이블로 제품을 벽면 콘센트에 연결한 다음, AC 전원 버튼을 눌러 가전제품에 동시에 전원을 공급하십시오.</p>

<figure class="hb-reference-figure hb-has-composite-art" data-component-id="HB-SPECIAL-REFERENCE-FIGURE" data-reference-id="op_ups" data-source-fragment-sha256="7c830925cd0dd8fe3fb5439b3fc67b932fe1dd0e4a8b32d03602f0e7af57820e" data-step-captions="embedded" data-web-composite-asset-key="frozen-source/op_ups" data-web-composite-locale="ko" data-web-composite-sha256="4b72807596c234238f2d7c0703c3757715b251dfb495136e3c138f145296054a" data-web-replace-key="reference.op_ups"><div aria-hidden="true" class="hb-composite-stage"><img alt="" class="hb-composite-art" loading="lazy" src="assets/ups.png"/></div><div class="hb-reference-semantic" data-reference-id="op_ups.semantic"><img alt="필수 조건: 제품이 켜져 있어야 합니다." class="hb-reference-art hb-composite-art" src="assets/ups.png"/></div></figure>

<p>무정전 전원 공급 장치(UPS)는 상용 전원(그리드 전력)이 중단될 때 부하에 자동으로 백업 전력을 제공하는 연속 전원 시스템의 한 유형입니다.</p>

<p>그리드 전력이 갑자기 중단되는 경우, Jackery Explorer 1000은 10 ms 이내에 저장된 전원으로 자동 전환되어 가전제품의 작동을 유지합니다.</p>

<p>UPS 모드에서는 정전 발생 전 장치의 최대 출력이 1,500W에 도달합니다.바이패스 모드에서는 동시 충전/방전이 가능하므로, 이 모드에서 실제 출력 전력은 정격 출력 전력보다 낮지만 정전 시에는 정격 출력 전력으로 복귀합니다.</p>

<table class="manual-callout-table manual-callout-table"><tbody><tr><td class="manual-callout-label">주의</td><td class="manual-callout-body"><ul><li>이 제품은 0ms 스위칭을 지원하지 않습니다.0ms 전환 전원 공급이 필요한 데이터 서버 또는 워크스테이션과 같은 장비에는 연결하지 마십시오.</li><li>사용 전에 기기와의 호환성을 여러 번 테스트하십시오.</li><li>제품의 최대 출력 전력을 초과하는 부하를 연결하지 마십시오.이 경우 과부하 보호 기능이 작동할 수 있습니다.</li></ul></td></tr></tbody></table>

## 2. 장치 추가

<p>2.1 <span aria-label="+" class="hb-inline-add-device-icon" data-component-id="HB-SPECIAL-APP" role="img">+</span> 버튼을 눌러 장치를 추가하십시오.</p>

<p>2.2 장치의 POWER 버튼을 눌러 전원을 켜십시오. 장치의 Wi-Fi 및 블루투스 아이콘이 깜박이면 네트워크 설정 모드에 진입했음을 의미합니다. "Icon Flashed" 버튼을 탭한 후, APP이 주변 기기에 연결할 수 있도록 블루투스 권한을 허용하십시오.</p>

<p>2.3 검색된 장치 아이콘을 탭하면 APP이 블루투스를 통해 자동으로 장치에 연결됩니다.</p>

<p>2.4 장치가 성공적으로 연결되면 Wi-Fi 비밀번호를 입력하고 OK 버튼을 탭하십시오.</p>

<p>장치가 APP에 성공적으로 추가되면, 장치의 Wi-Fi 아이콘이 항상 켜진 상태로 유지됩니다.</p>

## 3. 장치 바인딩 해제

<p>장치의 메인 인터페이스 오른쪽 상단에 있는 Settings 아이콘을 눌러 설정 페이지로 이동한 후, 페이지 하단의 Unbind 버튼을 눌러 장치 바인딩을 해제하십시오.</p>

## 4. 참고

<p>4.1 Wi-Fi 및 블루투스 켜기</p>

<ul><li>장치 전원이 켜지면 Wi-Fi 및 블루투스가 자동으로 켜지며, 화면의 Wi-Fi 및 블루투스 아이콘이 켜집니다.</li><li>화면의 Wi-Fi 및 블루투스 아이콘이 켜질 때까지 DC/USB 전원 버튼 + AC 전원 버튼을 동시에 길게 누르십시오.</li></ul>

<p>4.2 Wi-Fi 및 블루투스 끄기</p>

<p>화면의 Wi-Fi 및 블루투스 아이콘이 꺼질 때까지 DC/USB 전원 버튼 + AC 전원 버튼을 동시에 길게 누르십시오.</p>

<p>4.3 Wi-Fi 및 블루투스 재설정</p>

<p>POWER 버튼 + DC/USB 전원 버튼을 동시에 3초 동안 길게 눌러 Wi-Fi 및 블루투스를 공장 설정으로 재설정하십시오.연결된 APP 계정이 해제됩니다.</p>
