# HTE153 中规 DX2：待确认清单

日期：2026-11-19（按本次指示更新）

两份标注PDF只标已确定问题，下列事项独立列出。

## Q01 PD电源适配器到底接哪个输入口？

位置：说明书印刷第1、11、14页；后标贴输入/输出参数。

说明书印刷第1、11页写CCC及PD协议适配器，但第14页和后标贴只列AC IN1及DC8020 IN2/IN3输入，USB-C两口均列为输出。需确认是否支持经专用转接线接入DC8020；若支持，补充线材、接口和输入限制；若不支持，删除不适用的通用段落。

## Q02 全端口同时输出不降功率的依据

位置：说明书印刷第14页末尾，全端口同时输出脚注。

第14页脚注声明各端口同时使用不会降低功率。按标称值推算，AC总1500W + OUT1 120W + USB-C 30W、100W + USB-A 18W = 1768W。请核实是否可在宣称条件下持续实现，及SOC、环境温度、充电/旁路状态等限制；不能按单端口额定值自行推定整机实测性能。

## Q03 待机、节能与无线图标的固件定义

位置：说明书印刷第4、6、7页；PDF第1页总版中印刷第16页4.1。

第6页写无充放电2小时自动关机，节能模式又写12小时关输出；需说明AC/DC输出已开启但空载时哪个计时器生效。总版第16页4.1把无线图标“点亮”解释为已打开，而第4页以点亮/闪烁区分已连接/准备连接，建议按固件统一状态词，避免恢复漏页后继续含糊。

## Q04 认证版本与量产补贴内容

位置：后标贴标准、CCC锂电池补贴预留区、CMIIT ID。

后标贴引用GB 47372-2026，并预留另贴3C锂电池标贴（含生产日期、编码）的区域。需用本次JE-1000F中规产品、内部电池、无线模块的有效证书和批准标样确认标准版本、CCC补贴、生产日期格式、锂电池编码和CMIIT ID。空白预留区属于图纸安排，不能据此判断成品缺认证；成品标签样张尚未提供。

## Q05 标签擦拭试验与所列新标准的方法衔接

位置：后标贴技术要求第1、7条；GB 47372-2026第5.2.3条。

图纸技术要求1为清水15秒后汽油15秒，第7条为无水酒精150次。GB 47372-2026第5.2.3条规定的标识耐久性检验涉及清水及75%（体积分数）医用酒精各15秒。若本型号按该版标准认证，应补齐对应方法和判定要求；不能默认汽油或无水酒精试验可替代指定试验。

# 已标注冲突的修订取值

## M02 开机动作

已按操作者2026-11-19指示将印刷第15页App步骤2.2改为“短按”，此项已解决。

## M03 复位时长与清除范围

第15页按键名已按操作者指示改为“DC/USB输出按键”，名称冲突已解决。第9页现稿写“总电源+DC/USB，长按3秒”；App重置操作的按压时长、Wi-Fi/蓝牙/绑定及自定义设置清除范围仍待产品/固件确认，本次未新增说明。

## M04 节能阈值边界

确认25W及2W临界值是否包含在自动关闭条件中；据此统一“≤”或“低于”，并统一DC/USB称谓。

## M05 App界面文字

本册App/客服使用“电小二”；“Never Off”应核对当前中规App中的实际中文选项。太阳能板品牌及图中实物商标另按实物核对，不全局替换。

## L01 批准颜色

请以CMF、封样或批准分色文件确认最终底色和文字专色，统一“科技灰/专银”与“黑底白字”的矛盾。

## L02 粘着力单位和要求

若检验要求为每25mm试样宽度的剥离力，可写“≥1.0 kgf/25 mm”；请包装工程确认数值、试样宽度及试验方法，不能只猜改单位。
