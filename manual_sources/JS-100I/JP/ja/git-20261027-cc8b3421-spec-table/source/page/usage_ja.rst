使い方
==============================

Jackeryポータブル電源を充電します
------------------------------

ソーラーパネルをマルチ充電ケーブルでポータブル電源のDC入力ポートに接続します。

.. list-table::
   :header-rows: 0
   :widths: 14 86

   * - **ヒント**
     - | 1. ソーラーパネルの充電ケーブル端子は DC8020 です。
       | 2. ご使用のポータブル電源の入力端子の種類により、変換アダプターの必要有無が異なります。

ソーラーパネルの展開方法
------------------------------

1\. 収納バッグからソーラーパネルを取り出します。

.. image:: ../../assets/unfold_1.png
   :alt: 手順1の図

2\. 図のように、折り目に沿って順番に展開します。

.. image:: ../../assets/unfold_2.png
   :alt: 手順2の図

3\. 背面のスタンドを2本とも立てます。

.. image:: ../../assets/unfold_3.png
   :alt: 手順3の図

4\. ソーラーパネルを太陽の方向に向け、ポータブル電源に接続します。

.. image:: ../../assets/unfold_4.png
   :alt: 手順4の図

ソーラーパネルの収納方法
------------------------------

1.多機能充電ケーブルを取り外し、スタンドをたたみます。

.. image:: ../../assets/fold_1.png
   :alt: 収納手順1の図

2\. 図のように、折り目に沿ってソーラーパネルを順番に折りたたみます。

.. image:: ../../assets/fold_2.png
   :alt: 収納手順2の図

3\. ソーラーパネルを収納バッグに戻します。

.. image:: ../../assets/fold_3.png
   :alt: 収納手順3の図

ポータブル電源の入力端子が8020の場合
------------------------------

アダプターDC8020 - DC7909は不要です。ケーブルをそのまま接続してください。

------------------------------

別売りの「アダプターDC8020 - DC7909」を使用し、アダプターを接続したうえでポータブル電源に差し込んでください。

ポータブル電源の入力端子はUSB-Cの場合
------------------------------

| 別売りの「アダプター DC8020 - USB-C」をご使用ください。
| ケーブル8020端子 → アダプター DC8020 - USB-C → 本体USB-C (in/out)端子へ接続

SolarSaga アダプター (Pro/Plus/New専用)使用ガイド
------------------------------

SolarSaga アダプター (Pro/Plus/New専用)を使用すると、2枚または3枚のソーラーパネルをまとめて、本体のDC入力ポートに接続できます。

.. raw:: html

   <img alt="parallel" class="hb-source-reference" data-reference='{"id": "parallel", "web_replace_key": "reference.parallel", "capture_following_lines": 3, "presentation_mode": "base-art-live-copy", "base_art_layout": {"art_sha256": "a9d86035eae122d74fe873563b0572c52266b73ae67026712f10ae4b78888274", "panel_top": 0, "panel_fill": "#ffffff", "preserve_frame": true, "labels": [{"line": 0, "rect": [56.2, 9.4, 10.1, 4.1]}, {"line": 1, "rect": [43.1, 85.1, 41.5, 5.4]}, {"line": 2, "rect": [58.5, 92.1, 8.5, 4.7]}]}}' src="../../assets/parallel.png"/><div class="line-block"><div class="line">DC8020</div><div class="line">SolarSaga アダプター (Pro/Plus/New専用)</div><div class="line">別売り</div></div>

.. list-table::
   :header-rows: 0
   :widths: 14 86

   * - **ご注意**
     - | 接続できるソーラーパネルの最大枚数は、ポータブル電源のモデルによって異なります。
       | 必ず各モデルの接続ルールをご確認のうえ、正しく接続してください。
       | SolarSaga アダプター (Pro/Plus/New専用)のメス端子は8020のため、パネル充電ケーブ8020端子を接続してください。

太陽角度インジケーター
------------------------------

| 太陽光パネル正面には太陽角度インジケータが付いています。
| 日光が表面に当たると、その下部に影が表示されます。

.. raw:: html

   <img alt="angle" class="hb-source-reference" data-reference='{"id": "angle", "web_replace_key": "reference.angle", "capture_following_lines": 3, "presentation_mode": "base-art-live-copy", "base_art_layout": {"art_sha256": "cc6c96c9b5ff68b0f45e79bc9194664e4191ae9884e3e34095864790511b965e", "panel_top": 0, "panel_fill": "#ffffff", "preserve_frame": true, "labels": [{"line": 0, "rect": [55.8, 35.3, 29.1, 5.1]}, {"line": 1, "rect": [72.4, 64.0, 27.6, 5.0]}, {"line": 2, "rect": [72.5, 71.6, 10.1, 4.8]}]}}' src="../../assets/angle.png"/><div class="line-block"><div class="line">太陽角度インジケーター</div><div class="line">インジケーターポイント</div><div class="line">シャドウ</div></div>
