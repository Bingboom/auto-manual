# Deliberate Web layout differences from the printed JE-2000C US/en manual

Wording is never changed. These are layout decisions only.

1. Cover (p1) and back cover (p14, JACKERY INC. address and QR) are not on the Web page; printed page numbers are dropped.
2. Chapter titles are shared h2 strips; run-in titles are h3/h4 headings in the shared theme, which sets them in capitals.
3. The three preface paragraphs, printed above TECHNICAL SPECIFICATIONS without a title, open the first chapter before its heading.
4. Each specification group (GENERAL INFO, OUTPUT PORTS, INPUT PORTS, ENVIRONMENTAL OPERATING TEMPERATURE) is an HB-TABLE-SPEC with the group title as its section title; the three DC Input value lines are one row span.
5. The FCC MODIFICATION sentence stays where it is printed (top of page 02, after the trademark notes), apart from the FCC NOTE on page 11.
6. PACKAGE LIST cards use the shared HB-SPECIAL-INBOX grid; the card badge draws the printed ①–⑥ numbers.
7. The ①–㉑ LCD legend printed in three columns is one HB-TABLE-REFERENCE/lcd-descriptions list in number order.
8. Each LCD icon description block (icon, bold title, text) becomes a row of HB-TABLE-LCD-ICON (unnumbered), in two tables (p03 and p04 groups) with the Energy Saving Mode table and its on/off notes between them as printed.
9. The Warning : and DANGER: sentences become HB-CALLOUT-STRIP warning/danger with the signal word as label; the printed colon after the signal word is not repeated.
10. Printed bullet dots and the FCC "--" dashes are shared list markers. ❶–❹, a)–n) and 1)–5) markers are printed text and stay in the copy.
11. The FCC block is HB-SPECIAL-FCC/two-column: the shared FCC mark and NOTE paragraph on the left, the four measures on the right.
12. Warranty titled sections are a heading (the printed title) plus HB-WARRANTY-SECTION; 「Download the Jackery Mobile App」 is an h3 heading so the badge figure is not drawn inside the last warranty card.
13. Figure captions and leader labels printed inside panels stay in the panel art and are carried as alt text and IR metadata, not repeated as visible text.
14. On phones, the overview views and LCD map pan sideways inside the figure; the Energy Saving Mode table scrolls inside the shared table wrapper.
