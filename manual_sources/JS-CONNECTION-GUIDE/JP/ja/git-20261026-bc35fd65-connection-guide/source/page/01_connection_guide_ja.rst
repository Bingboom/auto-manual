Jackery Solar Genarator 接続ガイド
==================================================

詳細なソーラー発電機接続ガイドについては、公式のJackeryウェブサイトまたはカスタマーサポートをご参照ください。

.. container:: hb-text-panel

   **図に示されている接続の問題については、次の解決策を検討してください:**

   ※ DC7909 のオス・コネクタは DC8020 のメス・ポートに挿入できますが、互換性がないため、電流は流れません。
