## 保留不改

- 原稿疑点全部按批准包保留（见 `source_manifest.json` `source_concerns`）：如「DC入力ポートの電圧を一致させてください2つの…」与「保証提供地域保証は…」的连写、出カ、8A 与 12V/10A、ポータブル電源製品 等。
- 「ご注意」标签/正文两栏、保证卡片的深色标签标题、规格表与同梱品卡片沿用共享组件，与 JE-1000F JP Web 一致；手机端「ご注意」上下排列、标注排在图上，均为共享组件规则。
- 联系方式前的三个小图标（地球、信封、电话）未加入：仓库无可复用的共享图标，与 JBP-1000B-WH JP Web 先例一致只保留文字胶囊。
- 封底 QR 保持原资产字节；其余插图（概览、本体、ソーラー、車）与批准包逐字节一致。所有 recipe 资产维持 quarantine / build_eligible=false。
