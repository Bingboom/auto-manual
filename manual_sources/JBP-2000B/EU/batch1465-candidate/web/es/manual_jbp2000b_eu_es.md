# INFORMACIÓN IMPORTANTE DE SEGURIDAD

<p>Se deben seguir las precauciones básicas de seguridad al utilizar este producto, incluyendo:</p>




<ul class="simple">
<li><p>Lea todas las instrucciones antes de utilizar este producto.</p></li>
<li><p>Se requiere una atenta supervisión cuando se utiliza este producto cerca de los niños para reducir el riesgo.</p></li>
