# INFORMATIONS DE SÉCURITÉ IMPORTANTES

<p>Les précautions de base doivent être respectées lors de l'utilisation de ce produit, y compris :</p>




<ul class="simple">
<li><p>Veuillez lire toutes les instructions avant d'utiliser ce produit.</p></li>
<li><p>Une surveillance attentive est nécessaire lors de l'utilisation de ce produit à proximité d'enfants afin de réduire les risques.</p></li>
