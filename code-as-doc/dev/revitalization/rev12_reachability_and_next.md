HTTP 状态/耗时/是否完整渲染。URL 清单取自 [rev01_url_map.csv](rev01_url_map.csv)
与 [rev10_entry_map.md](rev10_entry_map.md)，最小集合如下：

| 项 | 样本 | 判定 |
|---|---|---|
| 门户首页 | `https://ht-doc.readthedocs.io/` | 可打开且 52 条目录渲染完整 |
| 文档正文页 | 任选 3 本（含一本多语书的非英语页） | 正文、目录、语言切换可用 |
| 静态资产 | 上述页面的图片/CSS 是否全部加载（开发者工具 Network 面板无失败项） | 无被拦资源 |
| 根别名跳转 | 任选 2 个根别名 URL | 跳转到正文且不白屏 |
| 统计信标 | `static.cloudflareinsights.com/beacon.min.js` | **预期在大陆被拦**（方案 M4 已注明）；被拦即确认"中规统计需换工具或注明口径" |
| RTD 平台域 | `readthedocs.io` 主域解析与握手 | 域级封锁会使以上全部失效，最先测 |

结论利用方式：任何一项失败都直接进入中规开线前置决策（换托管/绑自有域名/换统计），
全部通过也只代表"当次可达"，印码前仍按 §2 的稳定入口原则执行。
