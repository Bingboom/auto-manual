# 说明书插图交付说明（草案）

- 版本：草案 v0.1，2026-09-08
- 适用：说明书用插图与整页图的设计交付
- 状态：**尚未向设计团队发布。** 这是 Workstream Z A1 阶段的草案，
  待具体联系人、Illustrator 版本与字体授权确认后才成为正式要求。
- 依据与实测：[可编辑资产计划](editable_asset_delivery_debt_plan_2026-09.md) §3、
  [JE-1000F EU 母版实测](asset_pilot_a1_master_editability_2026-09.md)

## 为什么需要这份说明

说明书的插图现在只有成品图（PNG/PDF）进入构建系统，可编辑的设计源留在设计同事
本机或钉钉附件里。这带来三个具体问题：

1. 改一处标注文字，只能找到原作者重做，别人接不了手。
2. 说不清某一版说明书用的到底是哪一版图。
3. 出多语言版本时，图里的文字无法批量替换。

这份说明的目标是：交付一次，之后任何人都能打开、改、再交回来。

## 一、一份交付包包含什么

```text
<资产名>/<修订号>/
    source/       可编辑母版（.ai）及实际依赖
    exports/      按用途和语言导出的成品（SVG / PNG / PDF）
    preview/      一张评审用预览图
    说明.txt      见第四节
```

母版是必交项。只给成品图不算完成交付。

## 二、母版要求

### 2.1 保持可编辑

用 Illustrator 存 `.ai`，并勾选「创建 PDF 兼容文件」。不要交压平后的 PDF，
也不要交只是把 PNG 塞进容器里的假矢量文件。

判断标准很简单：换一台机器打开，能选中单个图形对象、能拖动、能改颜色。

### 2.2 需要改的文字必须是文字对象

凡是以后可能改动或需要翻译的文字（标注、引线标签、按键名、注意事项），
在母版里保持为**文字对象**，不要转曲。

验证办法：用文字工具点进去，能定位光标、能改字。

发布用的副本可以转曲，这是两回事——母版留活文字，导出物按需要转曲，两者都要交。

### 2.3 图层要有名字

不要留 `图层 1` / `图层 2` 这类默认名。按内容命名，例如
`机身` / `标注文字` / `引线` / `背景`。

实测发现：JE-1000F 欧规母版目前就是三个默认名图层，验收时无法判断哪层是什么。
这是本次要改掉的第一件事。

### 2.4 不要依赖本机文件

用到的图片请**嵌入**，不要用链接。交付前在另一台机器（或另一个目录）打开一次，
确认不弹「缺失链接」。

### 2.5 字体

- 请列出实际用到的字体名称和版本，写进说明文件。
- 不要留用不到的字体。实测 JE-1000F 欧规英文母版里混进了四款中日文字体和
  两款疑似残留西文字体，每款只用了一个字符——请在交付前清理。
- 字体文件在授权允许的前提下随包提供；不允许时，写明字体名称和获取方式。

## 三、色彩模式要写清楚

印刷说明书通常是单色黑（K）。网页版说明书是彩色的。

如果同一张图既上印刷又上网页，请在说明文件里写明当前是哪种，
以及是否需要另出彩色版本。不要默认「印刷什么样网页就什么样」。

实测：JE-1000F 欧规母版全书 23 页都是单色黑，包括 App 手机截图。
这在印刷上正常，但网页上是否接受灰度截图，需要业务确认。

## 四、说明文件要写什么

一份纯文本或表格，包含：

| 项 | 说明 |
| --- | --- |
| 资产名称与用途 | 这张图用在哪一章、做什么 |
| 适用型号 / 区域 / 语言 | 通用图请写「通用」，并说明通用的依据 |
| 是否为某张通用图的专用替代 | 若是，写明替代哪一张 |
| 派生来源 | 从哪份母版、哪个修订改出来的 |
| 修订说明 | 这一版改了什么 |
| 可编辑性 | 见下表 |
| 色彩模式 | 单色黑 / 彩色 |
| 字体依赖 | 名称、版本、是否随包提供 |

「派生来源」和「替代哪张图」是两件不同的事，请分开写。
前者说明设计上从哪来，后者说明构建时替换谁。

### 可编辑性分级

| 等级 | 含义 | 能否作为母版验收 |
| --- | --- | --- |
| 矢量 + 活文字 | 图形是路径，要改的文字是文字对象 | ✅ 首选 |
| 矢量 + 转曲文字 | 图形可改，文字已转曲 | 可作发布副本；须另附留活文字的母版 |
| 混合矢量/位图 | 部分对象可编辑，部分是嵌入位图 | 可以，但要写明哪部分是位图 |
| 位图封装 | 主体其实是 PNG/JPG，只是外面套了矢量容器 | ❌ 不能当可编辑母版验收 |

## 五、导出物

- 网页用：优先 SVG。需要有确定的尺寸/viewBox，资源自包含，不依赖运行时外部资源。
- 印刷用：PDF 或高分辨率 PNG。
- 位图的实际分辨率请按最终摆放尺寸给足，不要拿放大后的小图充数。

同一张图的不同格式，内容必须一致；文件本身的哈希不要求相同。

## 六、共享图与专用图

- 通用箭头、操作图标这类可以多个型号共用。
- **机身、接口、插座、屏幕的图不共用**——外观相似不等于可以替换。
  这类图请按型号单独出。
- 专用图请保存完整的独立母版，不要在共享母版上直接改。
  共享图更新时，不应该自动改变专用图的内容。

## 七、验收怎么做

资料侧收到交付包后会做这几件事，交付前可以自查：

1. 在另一台机器打开母版，确认无缺失链接、无字体替换提示。
2. 选中一个图形，改颜色或线条，保存，关闭，重新打开——改动还在。
3. 用文字工具改一段文字，保存重开——同样确认。
4. 检查图层是否有语义名称。
5. 核对说明文件的必填项。
6. 导出物与母版视觉一致。

只做渲染截图或看文件后缀不算通过。

## 八、待确认事项

- 网页版是否需要彩色变体，若需要由谁出。
- 图层命名规范的具体词表。
