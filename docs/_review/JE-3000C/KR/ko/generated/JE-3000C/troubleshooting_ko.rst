문제 해결
==========

다음 오류 코드 중 하나가 표시되면, 나열된 조치 방법을 따라 문제를 해결하십시오. 오류가 지속되면 Jackery 고객 지원팀에 문의하십시오.

.. list-table::
   :class: longtable
   :header-rows: 0
   :widths: 14 86

   * - 오류 코드
     - 조치 방법
   * - F0
     - 제품을 다시 시작하십시오.
   * - F1
     - 제품을 다시 시작하십시오.
   * - F2
     - 제품을 다시 시작하십시오.
   * - F3
     - 제품을 다시 시작하십시오.
   * - F4
     - 제품을 부하에 연결하여 오류가 사라질 때까지 배터리를 방전하십시오.
   * - F5
     - 오류가 사라질 때까지 태양광 패널 또는 AC 벽면 콘센트를 통해 제품을 충전하십시오.
   * - F6
     - | 1. AC 벽면 콘센트를 통해 제품을 충전하기 전에 전력망이 정상 상태로 돌아올 때까지 기다리십시오.
       | 2. 공기 흡입 및 배기구가 막혀 있는지 확인하고, 제품 양쪽에 20cm의 간격을 확보하십시오.
       | 3. 제품을 직사광선이나 고온 환경에 노출되지 않는 장소에 두십시오.
       | 4. 제품에서 모든 연결 장치를 분리하십시오. 제품을 사용하지 않은 상태로 두고 오류가 사라질 때까지 기다리십시오.
       | 5. 제품을 다시 시작하십시오.
   * - F7
     - | 1. 제품에서 모든 DC 입력을 제거하십시오.
       | 2. 연결된 태양광 패널의 개방회로 전압(Voc)을 확인하십시오. 제품의 최대 DC 입력 전압은 60V입니다.
       | 3. 제품을 다시 시작하고 유휴 상태로 유지하십시오. 오류가 사라질 때까지 기다리십시오.
   * - F8
     - Jackery 고객 지원팀에 문의하십시오.
   * - F9
     - 제품의 DC/USB 포트에 연결된 장치를 제거하십시오. 오류가 사라질 때까지 기다리십시오.
   * - FE
     - Jackery 고객 지원팀에 문의하십시오.
