Agent 怎样用这份语料库

  1. 飞书云文档 / Word 翻译预处理

    按记忆库替换原稿里能安全命中的句子：完全命中标黄，只差参数的标绿，没命中的保留原文。确认译文写进了文件，再上传到原文档所在目录，并列出没命中的高频句，供补进语料库。

  2. Markdown 按记忆库改写

    标题、列表、表格和图片保持不变，优先用记忆库里的句子和术语；没把握的句子保留原文，用 ==…== 标出。

  3. 确认后写回语料库

    译文经确认「入库」后写进对应语言，追加这门语言的维护记录并读回核对。写回后重跑预处理，这些句子就成了完全命中。

可以这样说：「把这篇飞书文档按记忆库做韩语翻译预处理，上传回原路径」
